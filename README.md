# AquaTransport

AquaTransport fixes connection issues on Mac OS X 10.6 –&nbsp;10.9. Based on [TLSFix](https://github.com/ObscureMosquito/TLSFix), originally written for iOS by nfzerox and ObscureMosquito. Mac-specific code written by Claude Opus 5.

This package replaces my older Aqua Proxy package.
