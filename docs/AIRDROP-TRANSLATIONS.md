# AirDrop UI translations

The English copy is user supplied. These translations cover the help link, popover, older-Mac action and Bluetooth controls.

## en

- Turn on Bluetooth to use AirDrop.
- Turn On Bluetooth
- Turning on Bluetooth…
- Could not turn on Bluetooth.
- Don't see who you're looking for?
- Search for an Older Mac
- Searching for older Macs…
- To share with someone using iOS, ask them to open Control Center and set AirDrop to Everyone. On a Mac, ask them to go to AirDrop in the Finder.
