# AquaTransport URL redirects.
#
# One rule per block, blocks separated by blank lines. Three lines each:
#   1. scope   -- "*" for every process, or a space-separated list of app bundle
#                 names ("Pages Numbers Keynote"). A trailing ".app" is optional.
#   2. from    -- matched as a URL prefix, so the remainder of the path and any
#                 query string are preserved.
#   3. to      -- replaces the matched prefix.
#
# Scope matches the process that actually issues the request. That is the app itself
# for WebKit1 apps (Dictionary, HelpViewer, iWork, Twitter) and for anything using
# NSURLConnection/NSURLSession directly. A WebKit2 app hands loads to the shared
# com.apple.WebKit.Networking service, so scoping a rule to Safari will NOT work.
